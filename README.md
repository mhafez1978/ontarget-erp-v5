## ░▒▓█ GETTING STARTED █▓▒░

### 📀 INSTALLATION

```bash
# Clone the repository
git clone <your-repo-url>
cd ontarget-erp-v5

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your database and API keys

# Initialize database
npx prisma generate
npx prisma db push

# Run development server
npm run dev
```

### 🎮 INITIAL SETUP

```
┌──────────────────────────────────────────────────────────┐
│  1. Navigate to http://localhost:3000/setup
|  * should redirect automatically to setup pag            │

│  4. Set your job title and hourly pay rate               │
│  5. You're ready to rock! 🎸                             │
└──────────────────────────────────────────────────────────┘
```

## ░▒▓█ KEY WORKFLOWS █▓▒░

### 🚀 ADDING A NEW EMPLOYEE

```
1. Navigate to Workforce Management
2. Click "Add Staff Member"
3. Fill in personal info (name, email, password)
4. Set employment details:
   • Role (Admin/Manager/Staff/Contractor)
   • Job Title
   • Employment Type
   • Pay Rate
5. Optional: Add to storefront "Meet the Team"
6. Save → Welcome email sent automatically!
```

### 📥 BULK IMPORTING DATA

```
1. Go to respective management section:
   • Customers → "Import Customers"
   • Products → "Import Products"
   • Services → "Import Services"
   • Workforce → "Import Workforce"

2. Download the sample template (CSV or XLSX)

3. Fill in your data following the template

4. Upload the file (drag & drop or click)

5. Preview & validate → Import!
```

## ░▒▓█ SAMPLE API ENDPOINTS █▓▒░

### Authentication

```
POST   /api/auth/login                # User login
POST   /api/auth/logout               # User logout
POST   /api/auth/register             # New user registration
GET    /api/auth/session              # Get current session
```

### Time Tracking

```
GET    /api/time-tracking/status      # Get clock-in status
POST   /api/time-tracking/clock-in    # Clock in
POST   /api/time-tracking/clock-out   # Clock out
POST   /api/time-tracking/break       # Start/end break
GET    /api/time-tracking/staff-status # Staff status overview
```

### User Management

```
GET    /api/settings/users            # List all users
PATCH  /api/settings/users/[id]/active # Enable/disable user
DELETE /api/settings/users/[id]       # Delete user (restricted)
```

### Company Management

```
GET    /api/companies/all             # List all companies
GET    /api/companies/my-owned        # User's owned companies
GET    /api/companies/user-companies  # User's member companies
```

### Bulk Operations

```
POST   /api/customers/bulk-upload     # Import customers
POST   /api/products/bulk-upload      # Import products
POST   /api/services/bulk-upload      # Import services
POST   /api/workforce/bulk-upload     # Import workforce
```
